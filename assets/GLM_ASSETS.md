# راهنمای دارایی‌های گرافیکی (GLM Assets)

این بازی طوری طراحی شده که تصاویر نهایی شما **بدون تغییر حتی یک خط کد موتور بازی** جایگزین placeholderها شوند.
کافی است فایل‌ها را با نام و مسیرهای زیر در پوشه `assets/` قرار دهید؛ سیستم `js/assets.js` خودش آن‌ها را بارگذاری می‌کند. اگر فایلی موجود نبود، بازی بدون خطا با placeholder رسمی ادامه می‌دهد.

---

## ۱. شخصیت اصلی: Byte

**محل:** `assets/characters/byte/`

| فایل | وضعیت | اندازه پیشنهادی | توضیح |
|---|---|---|---|
| `idle.png` | سکون/منو | 128×128 | حالت ایستاده، نمای جانبی رو به راست |
| `run_0.png` … `run_3.png` | دویدن | 128×128 | ۴ فریم چرخه دویدن، پاها در موقعیت‌های مختلف |
| `jump.png` | شروع پرش | 128×128 | بدن کشیده، پاها جمع |
| `fall.png` | سقوط | 128×128 | بازوها/پاها باز |
| `hurt.png` | آسیب | 128×128 | حالت خطا/الکتریکی |

**مشخصات فنی:**
- فرمت: PNG با پس‌زمینه شفاف (alpha)
- جهت دید: **نیم‌رخ رو به راست** (بازیکن به راست می‌دود)
- نقطه اتصال پا: **خط پایین تصویر** (bottom-center لنگر شود)
- ناحیه امن (safe margin): حداقل ۸px از هر لبه خالی بماند تا در صورت نیاز برش نخورد
- ضریب نمایش: ارتفاع تصویر روی صفحه ≈ ۶۰px معادل منطقی؛ عرض با حفظ نسبت ابعاد محاسبه می‌شود
- **نکته مهم:** فیزیک، hitbox و اندازه بازیکن از کانفیگ (`js/config.js` → `PLAYER_W/H`) می‌آید و با تعویض تصویر تغییری نمی‌کند.

**انیمیشن در کد:** چرخه دویدن با ۴ فریم در ~۹۰ms هر فریم (مستقل از FPS بازی). اگر sprite sheet تکی می‌دهید، فایل‌ها را همین‌طور جدا کنید یا در صورت نیاز بعداً فریم‌بُر اضافه می‌کنیم.

## ۲. موانع

**محل:** `assets/obstacles/`

نام فایل = `ob-<id>.png` و خودکار جایگزین رسم مربوطه می‌شود:

| فایل | مانع | اندازه پیشنهادی |
|---|---|---|
| `ob-syntax-bug.png` | Syntax Bug | 96×80 |
| `ob-null-pointer.png` | Null Pointer | 72×112 |
| `ob-memory-leak.png` | Memory Leak | 76×104 |
| `ob-firewall.png` | Firewall | 120×128 |
| `ob-broken-code.png` | Broken Code | 104×96 |
| `ob-server-failure.png` | Server Failure | 152×140 |
| `ob-stack-overflow.png` | Stack Overflow | 88×172 |

**نکات:**
- نمای جانبی، خوانا در اندازه کوچک، کنتراست بالا با پس‌زمینه تیره
- هاله نورانی در تصویر **نباید** از بدنه اصلی بیشتر از ۱۵٪ بیرون بزند (hitbox از هندسه داخلی محاسبه می‌شود)
- برای هر مانع در کد یک hitbox نسبتی (`box` در `js/obstacles.js`) ثبت شده؛ اگر طراحی شما خیلی متفاوت است اعلام کنید تا هماهنگ شود

## ۵. پوشه افکت‌ها

## ۶. چک‌لیست تحویل

- [ ] همه PNG با آلفا، بدون پس‌زمینه سفید
- [ ] نام فایل‌ها دقیقاً مطابق جدول (حروف کوچک، تیره‌پشت‌سر)
- [ ] نسبت ابعاد با جدول هماهنگ (تغییر جزئی OK است)
- [ ] تست: فایل‌ها را در مسیر درست بگذارید و `index.html` را باز کنید — بدون رفرش اضافه، تصویر جدید ظاهر می‌شود
