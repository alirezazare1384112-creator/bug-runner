# Bug Runner

بازی دونده بی‌پایان (endless runner) در جهان دیجیتال — HTML5 Canvas خالص، بدون وابستگی و بدون مرحله build.

## اجرا

`index.html` را در مرورگر باز کنید (کافی است پوشه را سرو کنید):

```
npx serve .
# یا
python -m http.server 8000
```

## گیم‌پلی

- پرش: Space / ↑ / کلیک / لمس (پرش دوم در هوا)
- توقف: Esc یا P
- از موانع بپر؛ برخی موانع سبک (Syntax Bug و Broken Code) با پرش از بالا **می‌شکنند** و امتیاز می‌دهند
- آیتم‌ها: Bit (۱۰ امتیاز)، Byte (۵۰)، Code Fragment (۸۰)، XP Core (۲۰۰ + ترمیم یک جان)

## محیط‌ها

مسافت طی‌شده محیط را عوض می‌کند (هر ۸۰۰ متر) با انتقال رنگی نرم:

1. **Code City** — شهر دیجیتال با پنجره‌های نورانی
2. **Neon Network** — گره‌ها و خطوط شبکه
3. **Server Room** — رک‌های سرور با چراغ‌های وضعیت
4. **Cyber Circuit** — مدارهای الکترونیکی با الکترون‌های متحرک
5. **Data Space** — بلوک‌های داده شناور

هر محیط سه لایه پارالاکس جداگانه دارد که با سرعت بازی هماهنگ می‌شوند.

## اتصال دارایی‌های GLM

فایل‌های PNG را با نام‌های `assets/characters/byte/run_0.png` و مشابه (مستند در `assets/GLM_ASSETS.md`) قرار دهید؛ بازی خودکار آن‌ها را جایگزین placeholder می‌کند. فیزیک و hitbox تغییری نمی‌کند.

## عملکرد

- حلقه بازی تکی با requestAnimationFrame و dt سقف‌دار
- ذرات از pool ثابت (حداکثر ۲۴۰) استفاده می‌کنند؛ با «کاهش جلوه‌ها» تعداد به ۳۵٪ کاهش می‌یابد
- رندر با DPR محدود (حداکثر ۲) مقیاس می‌شود
- با رفتن به تب دیگر بازی خودکار متوقف می‌شود

## پارامترهای QA (تست خودکار)

با query string می‌توان حالت‌های تست را بدون تعامل باز کرد:

| پارامتر | کار |
|---|---|
| `?play=1` | شروع خودکار بازی |
| `&t=60` | پیش‌راندن ۶۰ ثانیه شبیه‌سازی‌شده با بات پرش |
| `&nobot=1` | بدون بات (مرگ طبیعی برای تست صفحه گیم‌اور) |
| `&pause=1` | توقف خودکار برای تست اورلی |
| `&probe=1` | چاپ موقعیت المان‌های HUD در کنسول |

مثال: `index.html?play=1&t=70`

تست منطقی بدون مرورگر: `node test/smoke.js` (۴۹ بررسی)
